## Сценарии со скрина

1. Поиск клиентов на Картах: `smm-karty`.
2. Kwork, макеты и видеодемо VK/MAX, брендбук, контент, «Студия героя»: `smm-kwork`, `smm-mockup`, `smm-video`, `smm-brand`, `smm-content`, `smm-hero-studio`.
3. Карты, табло, публикация отчёта, личный радар VK: `smm-karty`, `smm-report`, `smm-radar`. Место радара на втором или третьем дне курса пока не закреплено.
4. Полная работа с клиентом: Карты → брендбук → упаковка VK/MAX → план, посты и истории → монтаж → табло и отчёт.

## Установка в Codex

Скопируй нужные папки из `skills` в `%USERPROFILE%\.codex\skills` (Windows) или `~/.codex/skills` (macOS/Linux). Существующие одноимённые папки сначала сохрани. Открой новый чат Codex. Здесь нет плагинов Claude и команд `/plugin`.

Пример для PowerShell (выполнять из папки этого репозитория):

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE/.codex/skills"
Copy-Item -Recurse ./skills/smm-karty "$env:USERPROFILE/.codex/skills/"
```

Проверка: `$smm-karty найди потенциальных клиентов среди салонов красоты Самары`. Другие примеры: `$smm-kwork подбери заказы на оформление VK`; `$smm-content подготовь неделю контента`; `$smm-report собери отчёт клиенту`.

## Что входит в первую версию

Это инструкции для Codex, а не готовые парсеры, видеоредактор или подключённый планировщик. Они задают процесс, проверяемые результаты и запасной путь при отсутствии инструментов. Реальная работа с сайтами, рендер видео, публикация и расписания требуют доступных в конкретном Codex инструментов и аккаунтов. Автоматизации сейчас не включены.

«Студия героя» пока трактуется как работа над образом эксперта или персонажа бренда; название из программы требует предметного уточнения перед разработкой отдельного приложения.
